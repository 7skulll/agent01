# BM25 改造与消融结果

日期：2026-10-15。链路保持单查询 BM25 + 向量 + 单次 RRF。

## 最终默认选择

- 保留中文双字词项，保留索引中的词频和顺序，查询条件去重。
- 统一 NFKC 和 casefold；完整保存含连字符、下划线、加号、井号的标识符。
- 文件名（去扩展名）、标题和正文独立索引，默认权重均为 1。
- 提供字段权重配置，修改权重无需重建；本次未证明标题提高到 2 倍有收益，因此不默认加权。
- 中文固定使用双字词项；已删除 jieba 实现、配置和依赖。下文分词实验数据仅作历史记录。
- 不增加同义词词典、查询改写/扩展、短语加权、额外排序或新的 RRF 层。

## 实验方式

真实 Embedding：qwen3.7-text-embedding-flash，1024 维。
原基础集：24 篇合成文件，20 个有答案问题、2 个无答案观察问题。
独立验证集：在第一轮结果出来前编写并固定，16 篇合成文件，12 个有答案问题、2 个无答案问题。

第一轮比较分词替换、字段拆分和标题加权，发现分词方案退步。第二轮补充了保留双字词项的
归一化、字段等权、标题加权方案；保留初定的 2 倍权重，没有逐题调参或增补同义词。
报告表格来自第二轮完整对照，每组内各方案复用相同文档和查询向量，向量指纹完全一致。
向量召回、候选池、阈值（0.2）与 RRF 权重（两路各 0.5，k=60）均固定。

每组的全部向量与合成资料只用于临时数据库，现有知识库未改动。

## 首条命中率

| 方案 | 原集 BM25 | 原集混合 | 验证集 BM25 | 验证集混合 |
|---|---:|---:|---:|---:|
| 原始基础版 | 90% | 95% | 100% | 100% |
| 归一化双字词项，单字段 | 90% | 95% | 100% | 100% |
| 双字词项，字段拆分等权（默认） | 90% | 95% | 100% | 100% |
| 双字词项，标题 2 倍 | 90% | 95% | 100% | 100% |
| jieba 等处理，单字段 | 85% | 90% | 100% | 100% |
| jieba 等处理，字段拆分等权 | 85% | 90% | 100% | 100% |
| jieba 等处理，标题 2 倍 | 85% | 85% | 100% | 100% |

默认方案与基础版的原集 BM25 Recall@3/5 均为 95%，MRR@10 均为 0.925；
混合 Recall@3/5 均为 100%，MRR@10 均为 0.975。
两组纯向量首条命中率均为 100%，各消融方案间向量排序一致。

**本轮没有证明整体检索命中率提升。** 已改善的是匹配规范性、标识符区分、字段可控性及
全文重建的独立性，不把这些工程改进表述为语义检索质量提升。

## 退步与限制

jieba 等处理方案会改变完整词与查询变体的匹配关系。例如：

- “人在家里，怎么连到单位内部系统？”在原词项方案中首条正确，分词替换后未首条命中。
- “登录口令想不起来了怎么办？”依然缺少口令/密码的对应关系，本轮没有通过改权重解决它。
- “我刚来公司上班，去哪里拿门卡和电脑？”分词等处理后也出现错误首条。

jieba 实验同时包含分词、少量停用词处理和小型 HR 词表，故不能把退步全部归因于分词算法本身。
两组数据很小，独立验证集已有明显的满分天花板，不能据此断言在真实文档上无退步。
无答案问题仍可能返回候选，本轮没有增加拒答模型或阈值校准。

耗时是单次顺序执行、复用查询向量之后的本地搜索耗时，存在预热和执行顺序影响；不据此宣称性能提升。

## 独立全文索引与升级

LexicalIndex 保存独立的全文版本；字段、词项规则与向量输入版本分离。
旧单列 FTS 表在启动迁移时被替换为新派生表，原文件、chunks、向量均保留。
调用 `POST /api/v1/knowledge-bases/default/index` 本地重建全文即可。

未重建时：keyword 明确返回 keyword_index_outdated，hybrid 降级到向量；不将过期索引解释成无资料。
已知旧版把 ordered-bigrams-v2 混入向量指纹的情况会在条件一致时迁移元数据，避免仅为全文改动重算向量。
模型、服务地址、切片或其他 Embedding 条件变化时，仍需正常重建向量。

回归测试验证：旧表迁移、无 Embedding 客户端重建、失败事务回滚、重新调用 index 重试、
向量与 chunk_id 不变、运行时字段权重、全半角和符号编号区分。

## 复现与报告

```bash
uv run python -m scripts.eval_bm25
uv run pytest -q
```

当前脚本仅比较四种双字词项方案，历史报告包含已移除的分词实验。使用配置的真实 Embedding。普通 eval_retrieval 则使用用户配置的 BM25 参数。

- 原集逐题/消融报告：evals/results/bm25-baseline.json
- 独立验证集逐题/消融报告：evals/results/bm25-holdout.json
- 独立验证集：evals/bm25_holdout.json

最终建议：先用真实知识库扩大验证，保留原问题失败样例；当前证据不足以默认启用 jieba、
提高标题权重或继续叠加查询策略。

删除分词实验后，全文版本已更新；升级后调用原 index 接口本地重建全文，现有向量有效时无需重新向量化。
