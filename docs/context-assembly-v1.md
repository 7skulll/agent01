# 上下文组装第一版

日期：2026-10-16。历史交付记录：当时任务图为 `chat-rag-v5`，组装版本为 `context-v1`。

当前仍使用该组装算法，任务图已升级为 `chat-rag-v6`。下文涉及数字引用、SSE 与旧图升级的描述仅记录第一版；当前协议以 [structured-answer-v2.md](structured-answer-v2.md) 为准。

## 行为

新 RAG 任务按“查询规划 → 检索 → 上下文组装 → 回答 → 引用校验”执行。
检索及最终组装请求分别保存 checkpoint。保留普通对话的工具循环；
知识库回答不绑定通用工具，以避免工具输出在资料装箱后再挤占上下文。
回答文本、引用编号和原有 SSE 事件保持兼容，新增 context_assembly 诊断事件。

- 模型默认只接收最近三轮、最多约 1536 tokens 的同库连续历史；切库后重置该窗口，
  问题改写使用相同隔离策略。完整会话、失败尝试和历史来源仍保存在原来的位置。
- 正文主块按文件、索引版本、标题、页码和连续 chunk_index 合并，组内恢复原文顺序。
  仅删除至少 16 个字符且精确相等的前后缀重叠；不模糊删除数字、标点或缩进。
- 先为独立主要证据分配空间、回收未用配额，再尝试邻居补全。邻居最多消耗资料预算的 20%。
  原有邻居开关继续生效，默认关闭；未新增数据库召回或模型调用。
- 超长正文使用原问题及已有改写问题的词项匹配选择原文句段，保留前后句，
  同时保留落在相邻主块边界的前提/例外。记录原文 chunk_id、字符 start/end 与实际文本。
- 表格、列表和代码保持完整块；无法容纳时明确记入 skipped_reasons。
  检索没有结果与结果无法装入资料预算，分别显示 no_retrieval_hits / no_context_fit。
- System 仅承载规则；最后一条 Human 消息通过 JSON 序列化承载 evidence 和原始 question。
  最终实际证据确定后才分配编号；来源 content 与传给模型的 content 一致。
- 文件名、标题、正文、消息包装都计量，完整请求再次复检，必要时先去除最旧历史、再收缩资料。
  BPE 仍是跨模型估算，保留现有安全比例与输出预留。
- 检索失败恢复复用已成功阶段；模型失败或重启恢复复用已保存的消息投影、来源和 prompt_hash，
  不按最新知识库内容重新组装。

## 配置

| 环境变量 | 默认值 | 说明 |
|---|---:|---|
| RAG_HISTORY_TOKENS | 1536 | 历史投影的估算 token 上限，0 关闭历史 |
| RAG_HISTORY_TURNS | 3 | 最近完整历史轮次上限，0 关闭历史 |
| RAG_NEIGHBOR_BUDGET_RATIO | 0.2 | 邻居预算比例上限，范围 0–0.5 |
| RAG_CONTEXT_TOKENS | 保留原配置 | 本轮资料总上限 |
| RAG_INPUT_TOKENS | 保留原配置 | 模型窗口分配依据，继续预留输出与安全余量 |

新增配置也兼容 RAG_RAG_ 前缀，但推荐使用上表名称。
本机原来的资料上限 4096、输出预留 2048 未改动。

## 诊断与来源

context_assembly 事件和 retrieval_end.diagnostics.context_assembly 包含：
候选/合并/最终证据数量、精确重叠删除字符数、抽取范围数、跳过原因、
资料/历史/元数据/完整输入估算、被丢弃历史轮数、知识库切换排除轮数、耗时、组装版本和请求哈希。
实际模型调用的 token_usage 事件继续报告估算及供应商实际用量。
元数据/历史/资料的分项不是严格可加的计费值，最终以完整输入计量及供应商用量为准。
来源快照新增 evidence_chunks，前端显示实际组装正文、抽取标记和片段数量，避免重复展示邻居正文。
请求日志不新增原文、问题或模型凭据。

## 升级与边界

无需数据库迁移、重新上传或重建向量/全文索引；新任务自动使用 v5。
旧 v4 等版本的未完成任务不能直接恢复或以相同幂等键重新启动，返回 graph_version_mismatch；
用户可取消旧任务后重新提交。已完成历史仍可读取并参与同库历史投影。

第一版没有新增父子块索引或跨页结构推断；没有 LLM 文本压缩或额外向量多样化调用。
句段抽取是确定性的词项启发式：超长单句不能安全容纳时可能跳过，不以字符硬截保证非空。
例外保留覆盖局部邻接关系，不代表所有业务条件都已被语义验证。
引用仍沿用现有数字编号校验；结构化回答和资料不足协议已在第二版完成；独立语义事实支持校验仍未实施。
业务质量提升仍需固定业务问题集的配对评估，本次未对真实用户文档执行该评估。
