已有文件无需重新上传、切片或向量化；旧会话标题为 null，仍显示短 ID。

## 文件下载与删除

文件页每行提供“下载”和“删除”。下载返回原始文件附件，使用 UTF-8 文件名，禁止浏览器内联解释。
删除需确认；它在同一事务中删除文件记录和级联的切片、向量、全文索引，并将原文件加入清理队列。
原文件清理失败不会恢复已删除记录，响应包含 cleanup_pending；服务启动、后续删除或手动清理时重试。
历史回答及其来源快照保留，删除后的原文件不能再下载。

索引执行中或该库存在 queued/running/paused/recovering 问答时拒绝删除，返回 409。
前端取消确认不会发起删除。文件 ID 必须属于 URL 指定的库，否则返回 404。
删除记录后可以用新的上传重新建立资料；原上传幂等键随原记录移除。

上传队列串行执行，其他文件上传期间可以重试先前失败的文件；重试项会继续被队列处理。
本地磁盘读写和删除在线程执行；取消写入会等待磁盘操作结束后清理，避免线程与补偿操作竞争。

## 上传残留清理

文件页“清理上传残留”作用于全部知识库；服务启动时也执行一次。
只扫描本项目的 default / UUID 目录内、符合 UUID 对象及临时 .part 命名规则、超过 24 小时的普通文件。
跳过符号链接、未知文件名和最近写入；已被 files.storage_path 引用的对象始终保留。
扫描与上传发布共用锁，覆盖对象写入到数据库提交，避免清理未提交上传。
待清理路径先持久化，失败留队列。手动响应报告新增入队数量及全局待重试数量。
目录扫描在线程执行，不占用事件循环。当前没有常驻定时清理任务，空目录不主动删除。

## 会话改名与删除

会话列表提供改名和删除按钮。名称去除首尾空白，允许 1–100 字，拒绝控制字符和无效 Unicode；
名称持久化到 conversations.title，列表按 updated_at 排序，刷新及重启后仍保留。
会话与问答历史使用统一分页缓存，自动刷新或操作后刷新会更新所有已加载页面。

删除需确认；数据库事务移除该会话全部任务、事件及会话元数据，知识库文件保留。
检查点通过 LangGraph Saver API 清理；失败进入持久化队列，服务启动或后续删会话时重试。
有未结束任务或任务协程尚未收尾时返回 409，请先完成或取消，再重试删除。
删除当前会话后界面返回空白问答页。再次访问被删会话或任务返回 404。

## 问答文件范围

问答输入框上方展开“问答范围”，可选全库或最多 100 个指定文件。
切换知识库会重置文件选择。普通聊天不发送文件限制。

- file_ids 为 null 或省略：当前知识库全部文件。
- file_ids 为 []：范围为空，不会回退全库；正常完成为资料不足，不调用回答模型。
- 非空列表：创建任务时验证文件属于当前库，去重并排序后持久化；不存在或跨库返回 422。

文件范围进入 runs、HTTP 结果、历史轮次及图状态，恢复后继续使用原限制。
同一幂等键更改范围返回 409；仅调整顺序或重复 ID 视为同一范围。
范围约束当前召回文件；已有历史仍按同库窗口供理解对话，不能作为本轮回答证据。
检索调试跳转问答仍仅传原问题和模式，需要在问答页自行选择文件。

## API

所有路径前缀为 `/api/v1`。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | /knowledge-bases/{kb_id}/files/{file_id}/download | 下载原始附件 |
| DELETE | /knowledge-bases/{kb_id}/files/{file_id} | 删除单文件及索引 |
| POST | /maintenance/files/gc | 清理过期上传残留并重试原文件队列 |
| PATCH | /conversations/{id} | `{"title":"项目咨询"}` 改名 |
| DELETE | /conversations/{id} | 删除会话及问答历史 |
| POST | /conversations/{id}/runs | 可选 `file_ids` 限定问答范围 |

接口继续采用统一结构化错误和 X-Request-ID；操作对象已经删除时返回 404。
