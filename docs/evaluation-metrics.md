# RAG 评测指标口径

更新：2026-10-27。本页说明评测页展示的九项核心指标的计算方式。
展示与报告的派生汇总在读取时计算，检索逐题指标也会在执行时保存。
失败题按下述规则计分；读取时不回写原始回答、检索来源或人工审核记录。

实验流程、证据追踪、案例集与门禁见 [评测第三版](evaluation-v3.md)。

## 分层评测

评测分为两层，避免把「检索没找到」和「模型答错」混成一个分数：

| 层 | 指标 | 回答的问题 | 数据来源 |
|---|---|---|---|
| 检索层（5 项） | Precision、Recall、Hit、MRR、nDCG | 该找的资料有没有被召回、排得靠不靠前 | 返回 sources + 人工标注的文件 ID |
| 生成层（4 项） | 忠实度、答案相关性、正确性、完整性 | 回答是否有依据、是否答非所问、是否正确、是否完整 | 人工审核字段（可选 RAGAS 另行并行） |

两层**永不合并成一个加权总分**。页面同时展示两层数值和分层诊断提示。
诊断阈值只用于定位问题：检索召回低且正确性高，优先查切分和召回；召回高但忠实度或正确性低，
优先查上下文裁剪、提示词和生成协议。

## 检索指标

排名单位是**返回片段中首次出现的文件去重顺序**，只取前 K 个文件（`file_ranking`）。
同一文件多个切片不重复获得命中收益。

| 指标 | 公式 | 说明 |
|---|---|---|
| 精准率 Precision@K | 命中相关文件数 / **K** | 分母固定为 K，返回不足时按空位补足 |
| 召回率 Recall@K | 命中相关文件数 / 标注相关文件总数 | |
| 命中率 Hit@K | 前 K 个文件中是否至少命中一个正相关文件 | 单题 0/1，批量取均值 |
| MRR@K | 1 / 第一个相关文件的排名；未命中为 0 | 衡量第一个正确结果出现得多早 |
| nDCG@K | DCG / IDCG，位置折扣 1/log2(rank+1)，二值相关性 | 0–1 归一化 |

**分母规则**（`summarize`）：

- 只有 `expected=answerable` 且 `judgment_scope=full` 的题进入均值；
- 已完成和**失败**题都进入分母；回答生成失败但保留检索结果时按实际检索计分，无可用检索结果的失败题计零；
- `partial`、`unlabelled`、`unanswerable`、取消和未执行的题不参与检索质量均值；
- 报告同时给出计分题数、失败数和部分标注题数，避免用小样本均值暗示总体准确率。

文件级指标只说明资料是否被召回。**命中相关文件不代表答案正确、引用充分或该拒答的题已拒答**，
回答质量必须另看人工审核和证据追踪。

## 回答质量指标

四项都是**严格二值判定**。分母只包含已明确审核为对应枚举值的**已完成且有回答**的题
（`ANSWER_METRIC_SPECS` 与 `review_metric_score`）。

| 指标 | 判定为 1 | 原始字段 | 严格性 |
|---|---|---|---|
| 忠实度 Faithfulness | 不存在无资料支持的表述 | `unsupported_claims=no` | `yes` 即计为不忠实 |
| 答案相关性 Answer Relevancy | 直接回应问题 | `answer_relevancy=relevant` | `partial` 计 0 |
| 正确性 Correctness | 人工总评通过 | `verdict=pass` | `partial` 不计为正确 |
| 完整性 Completeness | 必要事实完整覆盖 | `fact_coverage=full` | `partial` 不计为完整 |

规则：

- `pending`、`na`、缺失字段和失败题**不进入分母**；分母为 0 时显示「未评分」，**不显示 0%**。
  早于某个维度存在的旧记录没有该字段，按 `pending` 计入待审核数，不计入分母。
- 页面另外展示「含部分正确的可接受率」（`pass + partial`），但它**不替换**严格正确性。
- 人工总评、事实覆盖、引用语义支持、适用条件与拒答判断保留为独立维度，不合并成难以解释的加权总分。
- 派生指标只在读取时计算，**不回写**原始审核记录。

## 证据追踪指标

必要事实用原文锚点（文件 + 内容哈希 + 引文 + 页码）声明，在
**解析切片 → 召回候选 → 重排结果 → 选中来源 → 最终上下文** 五个阶段逐级做规范化子串匹配。

| 锚点状态 | 含义 |
|---|---|
| `matched` | 内容哈希一致且在切片中精确匹配 |
| `stale` | 文件内容已变化 |
| `unmapped` | 哈希一致但原文定位不到 |

任一必要事实的锚点无效时，整题证据**不评分**，归因为 `annotation_gap`——不把标注缺陷算成检索或解析的问题。
可评分时按阶段汇总覆盖率，并给出首个失败阶段：`retrieval_miss`、`rerank_loss`、
`selection_loss`、`assembly_loss`。

原文包含检查**不是语义事实验证**，只回答「这段原文是否到达该阶段」。

## RAGAS LLM-as-judge

可选的自动语义评分，运行在独立 worker 环境中。主服务不安装 ragas、pandas、datasets 或 pyarrow。
只对已完成且有答案标注、实际生成回答并有回答上下文的题评分；应拒答题使用独立的拒答指标，不混入生成层语义均值。无法评分时保存原因，不补零。

| 指标 | 含义 |
|---|---|
| `faithfulness` | 回答是否由检索上下文支持 |
| `answer_relevancy` | 回答是否直接回应问题 |
| `answer_correctness` | 结合参考答案判断事实正确性；无参考答案时留空 |
| `completeness` | 自定义 RAGAS `AspectCritic` 二值判断是否覆盖参考答案中的必要事实；无参考答案时留空 |

RAGAS 分数与人工审核**分开保存**：缺失分数不补零，不覆盖原始回答、检索结果或人工记录。
自定义完整性分数是一次二值判断，小遗漏也可能使其为 0；模型评审可能随运行波动，重要结论应结合原文证据与人工审核。
RAGAS 调用产生额外模型费用。API 省略评分选项时关闭；页面快捷评测在 worker 可用时默认启用，并可在运行前切换为人工审核。安装与协议见 [RAGAS worker](../tools/ragas-worker/README.md)。

本项目不引入 BLEU/ROUGE 这类字面匹配指标替代语义判断。

## 审计口径

- `failed` 的完整标注有答案题进入检索均值；有可用检索结果按实际结果计分，否则计零。
  `evaluation_inputs_changed` 不从旧来源补算；取消和未执行题不计入。
- 未审核、不适用、取消、未执行和服务失败**不会自动变成通过**。
- 对比实验的回答质量差值只比较 A、B 两次实验**同一道题在两边都已被明确审核**的情况；
  只在一侧审核的题计入「未配对」，不参与差值均值，避免审核覆盖度不同造成虚假提升。
- 回归门禁的任一检查项无数据时整体为 `unscored`，**`unscored` 不等于通过**。

## 展示与导出

- 检索指标随 K 的折线图展示精准率、召回率、命中率、MRR 和 nDCG，并保留可展开数值表。
- 回答质量柱状图展示四项指标及分子/分母、待审核和不适用数量。
- 同题实验对比展示检索指标差值和回答质量配对差值。
- 详情页、JSON 导出与 Markdown 报告通过同一派生读取流程生成；CSV 使用页面所载入的结果。

### 当前实验对比限制

`app/evaluation_comparison.py` 的 `score()` 仍将所有失败题的检索得分计零，
对比和回归门禁也使用未做历史失败题补算的记录。它们与详情页的失败题口径尚未统一：
若召回成功但生成失败，可能把生成故障显示为检索退化。使用门禁前需核对逐题来源与失败原因；
这属于待修复实现问题，不应改写历史结果消除差异。

## 边界

小样本均值不推断生产准确率或统计显著性。原文包含检查不是语义事实核验，
人工通过也不等于完整业务验收。指标是文件级二值相关性，不评价段落排序质量。
需要业务签收时，应使用已核验、冻结的案例集并保留原始审核记录。
