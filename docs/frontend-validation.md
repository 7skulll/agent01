# 第一版前端验证记录

日期：2026-10-16，后续增量更新至 2026-10-19。各节记录当时版本的验证范围。

## 已交付

- `frontend/`：Vue 3 + TypeScript + Vite，中文浅色工作台，问答/文件/检索三个页面。
- 问答：真实 API 接入、会话分页、流式草稿、最终回答、引用抽屉、暂停/恢复/取消、自动重连、幂等提交及刷新恢复。
- 文件：多文件串行上传、格式/大小校验、独立幂等重试、分页、批量索引、全文和向量独立状态。
- 检索：三种模式、扩展查询、文件范围、原始分数、重排/降级/耗时诊断。
- 后端：新增 `GET /api/v1/conversations/{id}/turns`，默认最新在前，支持 limit/offset。来源从任务记录读取，committed 依据 checkpoint/base_run_id 递归关联，无需新增迁移。
- 公开合成演示文档、启动说明、API 类型快照和 nginx 同源托管示例。
